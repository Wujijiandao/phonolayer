# Contributing to PhonoLayer

PhonoLayer is in public-beta preparation. Small, reviewable contributions are welcome once the repository is public.

## Ground rules

- Keep the desktop core local-first and usable without an account.
- Do not add telemetry, analytics, advertising SDKs, or network-dependent learning features without an explicit design discussion.
- Do not submit copyrighted study texts, lyrics, exam questions, private chat logs, or other material you do not have the right to redistribute.
- Preserve the distinction between machine proposals and user-confirmed knowledge.
- Preserve `.phonodoc` / `.phonodb` compatibility rules unless a migration plan and fixtures are included.
- Add or update tests for semantic invariants, not only UI happy paths.

By contributing, you represent that you have the right to submit the contribution and agree that it is provided under the repository's MPL-2.0 license.

For substantial feature work, open an issue first so the data model and Manual-first principles can be reviewed before implementation.
