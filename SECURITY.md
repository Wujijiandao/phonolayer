# Security Policy

PhonoLayer handles local learning documents and a local personal-memory database. Security issues involving file parsing, archive validation, path handling, sandboxing, recovery data, or unintended network access are treated as high priority.

Please do not post exploit details or sensitive user data in a public issue. Once the public repository enables GitHub private vulnerability reporting, use that channel. Until then, contact the maintainer through the maintainer profile and request a private reporting channel.

Supported public-beta line: `0.9.x`.
