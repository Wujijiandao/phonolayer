# Supporting PhonoLayer

PhonoLayer's desktop core is intended to remain free and local-first.

Voluntary support channels are **not configured yet**. When official donation/sponsorship links are created, they will be listed only in the official repository and project website.

The intended model is:

- free local desktop core;
- open and auditable `.phonodoc` / `.phonodb` formats;
- voluntary sponsorship;
- optional paid official sync/backup service in the future, if users actually want it.

Core document editing, local Personal Memory, retrieval workflows, and file ownership are not planned as artificial paywalls.
