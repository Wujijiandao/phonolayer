官方学习样例

Windows 文件外观

实验开发期

PDF / 打印输出设置

预览会先生成临时 PDF，再交给 Windows 默认 PDF 查看器打开；正式导出仍使用矢量文字与 SVG。分页规则已加入孤行/寡行保护，并尽量避免标题、图片和表音对象被切断。
