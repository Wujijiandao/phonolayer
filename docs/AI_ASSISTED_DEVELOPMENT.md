# AI-Assisted Development Disclosure

PhonoLayer has been developed through human-directed iterative design with substantial AI assistance, including code drafting, documentation, QA design, debugging, and architecture review.

The human maintainer selects the product goals, approves changes, curates releases, and is responsible for the distributed project. AI systems are not listed as copyright holders or maintainers.

Public releases should continue to treat generated code and documentation like any other contribution: review it, test it, verify licensing boundaries, and avoid representing unverified output as established fact.
