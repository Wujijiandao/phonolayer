# Editing Essentials 0.6.6

## 目标

PhonoLayer不是复刻完整 Microsoft Word，而是借用成熟办公软件的操作习惯，为语言学习文档保留最常用的文字处理能力。

## Ribbon：视图

### 换行符标记

PhonoLayer以灰色 `↵` 作为显式换行的视图标记。标记由独立 overlay 生成：

- 不进入正文 HTML；
- 不改变光标和文字排版；
- 不参与 `.phonodoc` 的知识内容；
- 不进入 PDF / 打印。

### 页边距标记

四个 L 形灰色角标定位于纸张正文内容区四角。位置由：

- 当前纸张尺寸；
- 当前页边距；
- 当前屏幕缩放；
- 当前纸张屏幕位置

实时计算。它们仅用于帮助学习者感知正文可用区域。

## 设计边界

v0.6.6 不加入公式、脚注、目录、复杂对象等功能。后续是否加入，取决于实际学习工作流，而不是“因为 Word 有所以PhonoLayer也要有”。
