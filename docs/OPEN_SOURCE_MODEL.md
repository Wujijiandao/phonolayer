# Open-Source and Sustainability Model

PhonoLayer follows four commitments during the public beta:

1. **Free local core.** Core desktop learning workflows remain usable locally without an account.
2. **User-owned data.** `.phonodoc` and `.phonodb` are documented, portable local formats.
3. **Auditable behavior.** Manual-first confirmation, stale-state semantics, retrieval evidence, and migrations remain inspectable in source and format documentation.
4. **Optional services, not captivity.** A future official sync/backup service may be paid, but the local core and local files should remain usable without it.

The project uses MPL-2.0 so modifications to MPL-covered source files remain available under the same license while allowing the program to interoperate with separately licensed software and future services.
