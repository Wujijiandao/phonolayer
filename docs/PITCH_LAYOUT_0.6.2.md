# 五度音高排版模型 — v0.6.2

## 目标

五度音高是学习者人工填写的数据的可视化层。排版器不得因为音高点数、粤拼/拼音字符串长度而人为制造正文字符间距。

## 两层几何

每个表音对象同时具有：

1. **track geometry**：五条水平底线覆盖该 ruby 对象的实际排版 advance width。
2. **base geometry**：蓝色音高轨迹只映射到下方 base text 的真实几何范围。

因此长罗马字标签可以正常居中显示，但不会决定音高轨迹应该落在哪个汉字上。

## 连续规则

- 两个 ruby 对象在 DOM 中直接相邻、原文没有空格或标点时，各自 track 的左右边界自然相接。
- 不人为加入固定 margin、separator 或 pitch gap。
- 原文有空格、标点、普通正文时，浏览器原本的文字 advance 就形成真实间隔。
- 同一多字 ruby 内，如果人工音高用 `|` 分成多个轨迹，五条底线仍是一条连续轨道；每条轨迹在 base span 内按等宽 cell 布局。

## Manual-first

这里只改变绘制几何。`ma3`、`jat1`、假名等不会自动推导任何五度音高；只有用户明确填写的 `5-5`、`2-1-4` 等人工音高参与绘制。
