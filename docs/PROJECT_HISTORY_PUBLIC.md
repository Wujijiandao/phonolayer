# Public Project History

PhonoLayer evolved from a small manual phonetic-annotation editor into a document-centric phonological learning workspace.

Milestones:

- 0.1–0.2: ruby/phonetic annotation and basic study display;
- 0.3–0.4: Manual-first document model, `.phonodoc`, personal observations, real-document workflow;
- 0.5–0.6: Electron desktop shell, Windows integration, archive/recovery/PDF/editing reliability;
- 0.7: study workflow, interaction model, retrieval sessions;
- 0.8: Personal Phonological Memory, Japanese mora/accent model, direct annotation editing, high-zoom and semantic-integrity hardening;
- 0.9.0: format-freeze candidate for `.phonodoc` / `.phonodb`;
- 0.9.1: public/private separation, open-source licensing, public demo corpus, privacy/security/contribution documentation, and public-facing PhonoLayer identity;
- 0.9.3: locked Electron runtime provenance, checksum verification, dependency inventory and owner-side offline runtime backup workflow.
- 0.9.4: integrated official promotional artwork and added a small one-click Windows setup UX over the same locked runtime chain.
- 0.9.5: replaced the provisional visual assets with the unified `文 + layered pages + waveform` brand set; schemas and learning behavior unchanged.
- 0.9.2: canonical **文之形声 · PhonoLayer** branding and an expanded seven-document official public learning corpus.
