# v0.9.4 — Windows Setup UX & Promo Integration

This release does not change the `.phonodoc` or `.phonodb` schemas. It integrates the official promotional artwork into the public package/README and adds a Windows 11 one-click setup dialog over the existing locked Electron runtime chain.

Release goals:

- preserve the v0.9.3 SHA-256-locked Electron supply chain;
- make first-run setup understandable to non-developers;
- keep a command-line recovery path;
- avoid administrator privileges and machine-wide installation;
- create optional shortcuts and per-user `.phonodoc` integration;
- keep the public package free of owner-private study material.
