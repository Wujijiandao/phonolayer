# Public Sample Policy

The public distribution must contain only redistributable material.

Current public learning corpus:

- five official multilingual-learning guides under `samples/public/Official_Learning_Guides/`;
- one original Japanese reading demo;
- one original Cantonese/Jyutping demo.

All text was authored specifically for **文之形声 · PhonoLayer** and is dedicated to CC0-1.0.

The official guides explain project learning concepts rather than claiming experimentally proven superiority. They distinguish target-language material from cross-language metalanguage, document/form/sound layers, retrieval evidence from mastery inference, and personal memory from dictionary authority.

A public release MUST NOT include the owner's private corpus, private provenance/audit exports, lyrics, exam questions, game scripts, or third-party reference subsets unless a separate rights review explicitly approves redistribution.

Release QA scans for known private paths/names and fails if they appear in the public archive.
