# Official Public Learning Samples

These `.phonodoc` files are original public learning material created specifically for **文之形声 · PhonoLayer**. They do not contain the owner's private study corpus.

## Official learning guides

- `Official_Learning_Guides/00_Multilingual_Learning_Overview.phonodoc` — “语言材料分开，元语言知识连起来”。
- `Official_Learning_Guides/01_Text_Form_Sound.phonodoc` — 文、形、声的分层；真实读音优先于机械拆字。
- `Official_Learning_Guides/02_Retrieval_Before_Reveal.phonodoc` — 先回忆再揭示；行为证据与掌握度分离。
- `Official_Learning_Guides/03_Cross_Language_Transfer.phonodoc` — 跨语言迁移的边界：连接而不混写。
- `Official_Learning_Guides/04_Personal_Phonological_Memory.phonodoc` — 个人语音记忆不是词典。

## Language demos

- `Japanese/Japanese_Reading_Demo.phonodoc` — original Japanese reading-annotation demo.
- `Cantonese/Cantonese_Reading_Demo.phonodoc` — original Cantonese/Jyutping demo.
